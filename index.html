How it works

Set it up once. Then it stays quiet.

Paste a read-only key

It can see usage numbers. It cannot make requests, read prompts, or change anything.

It learns your normal

Each hour is compared with the same hour over your last 14 days, so a busy Monday morning is not a spike.

You get one message

Only when spend crosses your line. Default is 3x and at least $5 an hour. Then a 6-hour cooldown.

Baselines, floors, cooldowns and a worked example are on the product page.

Before you ask

Straight answers.

What can the key actually access?

Usage and cost numbers only. It is a read-only admin key: it cannot send requests to the model, read prompts or responses, or change any setting. The security page has the details.

Will it spam me?

No. You get one message when an hour crosses your threshold, then a cooldown (6 hours by default) so a long incident is one alert, not twenty. Plus one summary on Mondays, which you can switch off.

Does it stop the spending?

No, on purpose. Spikewatch never switches your service off, because a false cap during a real traffic spike costs more than the bill. It tells a human within the hour so you decide.

Which providers does it support?

Anthropic usage reports work today, in the live checker and the self-hosted engine. You can also paste any hourly spend as CSV into the checker. More providers are planned for the hosted version.

Can I run it myself for free?

Yes. The engine is open source and runs as an hourly GitHub Action with two secrets. The self-host guide walks through it. The paid version is for teams who would rather not maintain it.
